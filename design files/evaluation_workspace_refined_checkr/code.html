Question 4: Explain AVL Tree balancing rotations (Left-Left and Left-Right) and show their time complexity derivation. [10 Marks]
✓

Ans 4) Balance Factor (BF):
Defined as the height difference between left and right subtree:
BF(node) = Height(Left_Child) - Height(Right_Child)
For balanced AVL trees, invariant condition is: BF ∈ {-1, 0, +1}.

✓
(a) Left-Left (LL) Rotation:

Occurs when insertion happens in left subtree of left child. Fixed via single Right Rotation at Z:

Unbalanced (BF = +2)
trending_flat Right Rotate(Z)
Balanced (BF = 0)
✕
(b) Left-Right (LR) Rotation:

For LR rotation, we perform a double rotation. Left rotate left-child, followed by Right rotate parent. Result directly jumps to final root.

✓
(c) Time Complexity Derivation:

Height h ≤ 1.44 log₂(n) ⇒ Tree height is O(log n).
Rotation operations involve O(1) constant pointer re-assignments.
Total Cost = Search + Balancing = O(log n) + O(1) = O(log n).
